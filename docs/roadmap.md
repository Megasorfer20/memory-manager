# Roadmap del proyecto final

## Fase 1: lógica base

- definir memoria total
- crear procesos
- mostrar memoria
- terminar procesos

## Fase 2: fragmentación y compactación

- detectar huecos libres
- compactar memoria
- recalcular posiciones de procesos

## Fase 3: paginación

- definir páginas
- asignar frames
- mostrar página por proceso

## Fase 4: SWAP

- mover procesos a SWAP
- recuperar desde SWAP
- manejar memoria insuficiente

## Fase 5: CLI

- menú interactivo
- validaciones de entrada
- manejo de errores

## Fase 6: API REST

- endpoints para memoria y procesos
- JSON uniforme para respuestas
- validación centralizada
- soporte para frontend y pruebas reales

## Fase 7: frontend con React

- dashboard visual final
- estadísticas de memoria
- detalle de proceso
- filtros y búsqueda
- interacción con SWAP y compactación

## Fase 8: integración y pruebas

- pruebas de núcleo de simulación
- pruebas de API HTTP
- validación end-to-end del flujo completo
- preparación para presentación final

## Estado final del proyecto

El proyecto ya está en una versión completa para educación y demostración:

- lógica central funcionando
- API REST disponible
- frontend visual interactivo y más robusto
- documentación para ejecución y uso
- validación automatizada con pruebas
